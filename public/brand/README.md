# ELIKE artwork

Web vectors converted from the user-supplied ELIKE WORDMARK.pdf and ELIKE LOGO.pdf using Poppler pdftocairo. Original letterforms and bee paths are preserved. Artwork bounds are cropped through the SVG viewBox. Masks remove the original background and cutout fills for transparent use.

- elike-wordmark.svg: original wordmark for light surfaces.
- elike-wordmark-reverse.svg: off-white letterforms; original gold is preserved.
- elike-wordmark-on-gold.svg: original ink/gold artwork with transparent cutouts.
- elike-bee.svg: original gradient bee.
- elike-bee-flat.svg: same bee, gold fill, for small/repeated marks.
- elike-bee-ink.svg: same bee, ink fill, for gold surfaces.

The wordmark and standalone bee are distinct supplied artwork; neither has been redrawn. Set explicit CSS height and automatic width. The PDF artboards were not delivered as the pre-exported SVG archive mentioned in the brief.
